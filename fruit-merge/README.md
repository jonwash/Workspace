# Fruit Merge

A Suika-style fruit merge game in a single self-contained HTML file — no dependencies, no build step.

**Play:** open `index.html` in any browser.

## How to play

- Move the mouse (or drag on touch) to aim, click/tap to drop the fruit.
- Keyboard: ←/→ to aim, Space or ↓ to drop.
- Two touching fruits of the same kind merge into the next bigger fruit and score points.
- Eleven tiers: cherry → strawberry → grape → dekopon → orange → apple → pear → peach → pineapple → melon → watermelon. Merging two watermelons clears them for a +200 bonus.
- If the pile rests above the dashed red line, the game is over. Best score is saved locally.
